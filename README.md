# CAM Assistant

Telegram-бот для наладчика ЧПУ: контурная УП для Fanuc, расчёт сверления, резьбы и режимов резания.

## Запуск

1. Установите Python 3.11 или новее.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Создайте переменную окружения `BOT_TOKEN` со значением токена Telegram-бота.
4. Запустите: `python bot.py`.

Токен не хранится в исходном коде. Не добавляйте файл `.env` в Git.

## Render

Создайте Background Worker из этого репозитория. Команда сборки: `pip install -r requirements.txt`. Команда запуска: `python bot.py`. В Environment добавьте `BOT_TOKEN`.

## Разделы

- Контур: прямоугольный внешний контур, положение XY/Z нуля, диаметр инструмента, шаг по Z, радиус углов, S/F.
- Сверление: генерация координатной УП с циклами G81/G83 по введённым точкам.
- Резьба: генерация координатной УП G84, подача F = S × шаг.
- Режимы резания: расчёт S и F из Vc, fz, диаметра и числа зубьев.

## Ограничения безопасности

Сгенерированный NC-файл является черновой программой. До запуска на станке обязательны проверка инструмента и корректора H, G54, нуля Z, безопасных высот, зажима заготовки, ограничений осей, симуляция и пробный прогон. Программа не заменяет CAM-симулятор или проверку наладчиком.

Контурная операция поддерживает прямоугольник с острыми или одинаково скруглёнными углами, радиальную черновую траекторию с припуском и отдельный проход по номинальному размеру. Сверление и нарезание резьбы поддерживают ввод координат отверстий. Карманы, полноценная библиотека материалов и автоматический подбор режимов под конкретную марку материала пока не реализованы.
